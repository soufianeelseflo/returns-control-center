# Returns Control Center

A production-minded portfolio project for e-commerce **returns, refunds, RMA policy and warehouse disposition**.

## Why this project exists
Most storefront demos stop at checkout. Real commerce teams spend significant time on post-purchase operations. This project demonstrates the less glamorous production concerns: return eligibility, refund exposure, fraud/risk routing, inventory disposition, audit history and API boundaries.

## Highlights
- Next.js 16 App Router + React 19 + strict TypeScript
- Tailwind CSS 4 via the current PostCSS plugin
- Searchable returns queue and RMA detail pages
- Explicit policy/eligibility rules separated from UI
- Refund calculation and risk-based routing
- Warehouse disposition workflow
- Audit timeline and operational KPIs
- Typed API routes with validation and HTTP errors
- GitHub Actions CI for typecheck + production build

## Run locally
```bash
npm install
npm run typecheck
npm run build
npm run dev
```
